# Прокси для библейских обоев

Cloudflare Worker, который отдаёт **готовый JPEG** с Vercel по обычной
статической ссылке. Нужен потому, что прямой адрес Vercel блокируется
у части провайдеров, а Cloudflare работает.

## Деплой (1 раз, ~2 минуты)

Нажми кнопку и войди в Cloudflare (аккаунт бесплатный, карта не нужна):

**https://deploy.workers.cloudflare.com/?url=https://github.com/Misha1202/motivation-wallpaper-proxy**

После деплоя получишь ссылку вида:

```
https://motivation-wallpaper-proxy.<твой-субдомен>.workers.dev/
```

Открой её в браузере телефона — должна открыться картинка. Обнови
страницу — картинка другая.

## Шорткат

В действии **«Получить содержимое URL»** укажи эту ссылку целиком.
Никаких random-параметров и дополнительных действий не нужно.

## Как это работает

Worker на каждый запрос:

1. добавляет уникальный `_cb`, чтобы не было кеша;
2. запрашивает `https://motivation-wallpaper2.vercel.app/api/image`;
3. возвращает JPEG с `Cache-Control: no-store`.

Картинка по-прежнему генерируется онлайн на Vercel при каждом запросе.

## Ручной деплой

Если кнопка не сработала:

1. Cloudflare → **Workers & Pages** → **Create** → **Worker**.
2. Вставь код из `src/index.js`.
3. **Deploy**.
